Calculadora de porcentagem

Calcule uma parcela percentual, compare a variação entre valores ou descubra a proporção de uma parte no total.

Escolha a operação

Campos que se adaptam

Ao trocar a operação, os rótulos indicam se o campo representa percentual, valor inicial, parte ou total.

Para uma promoção, use a calculadora de desconto.

Como escolher o cálculo correto

  1. Use A% de B para comissão, imposto ou parcela percentual de um valor.
  2. Use Variação de A para B para comparar preço, faturamento ou custo entre dois momentos.
  3. Use A representa quantos % de B para medir a participação de uma parte no total.

Por que o valor inicial não pode ser zero?

Na variação percentual, o valor inicial é o divisor. Divisão por zero não é definida. Se algo passou de zero para um valor positivo, informe a diferença absoluta em vez de atribuir um percentual infinito.

Redução e aumento não se anulam

Uma queda de 20% seguida de alta de 20% não retorna ao valor original: R$ 100 cai para R$ 80 e depois sobe para R$ 96. A base da segunda operação mudou.

Dúvidas sobre porcentagem

O resultado da variação pode passar de 100%?

Sim. Passar de 50 para 125 é um aumento de 150%, pois o acréscimo de 75 equivale a uma vez e meia o valor inicial.

Posso usar números negativos?

A ferramenta geral aceita números negativos. Ao interpretar variação com bases negativas, considere o contexto: o percentual matemático pode não representar bem uma mudança de prejuízo para lucro.

Porcentagem e ponto percentual são iguais?

Não. Uma taxa que vai de 10% para 12% sobe 2 pontos percentuais, mas teve aumento relativo de 20%.
